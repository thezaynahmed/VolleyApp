# VolleyApp

Android networking demo using the Google Volley library to fetch and parse JSON data from a REST endpoint.

## Features
- Sends HTTP GET requests via Volley `RequestQueue`
- Parses JSON arrays and objects
- Displays fetched data in the UI

## Built With
- Java
- Android Volley Library
- Android SDK

## How to Run
Open in Android Studio and run on an emulator or device with internet access.
